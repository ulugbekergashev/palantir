# Телефон клиники: MicroSIP + запись разговоров

Cerebro не зависит от API оператора: подходит любой SIP-оператор (UTEL, Uztelecom, Sipuni, OnlinePBX и т. д.). Разговор идёт через бесплатный софтфон **MicroSIP** на ПК регистратуры, Cerebro видит каждый звонок и записывает разговор.

## Что происходит
| Событие | Что делает Cerebro |
|---|---|
| Входящий, никто не взял | заявка «Перезвонить» регистратуре в Telegram (повторный звонок с того же номера — в ту же заявку: «Yana qo'ng'iroq qildi») |
| Кнопка «📞 Kompyuterdan qo'ng'iroq» на заявке | MicroSIP сам набирает номер; звонок привязывается к заявке |
| Исходящий, не взяли | в заявку пишется попытка «Ko'tarmadi», напоминание через 30 мин |
| Разговор состоялся | запись → текст (узбекский; с VoiceLab — с разделением голосов) → разбор ИИ: кто, что хотел, о чём договорились, следующий шаг, оценка сотрудника → карточка клиента, заявка, короткое сообщение владельцу |
| Номер есть у клиента из Instagram/Telegram или пациента DentaCRM | всё в одной карточке клиента |

Панель → «Qo'ng'iroqlar»: журнал, прослушивание записи, текст, разбор.

## Подключение
1. Установить MicroSIP (microsip.org) **на тот же ПК, где работает Cerebro**.
2. MicroSIP → «Add account»: сервер, логин, пароль от оператора. Позвонить себе — убедиться, что звонки идут.
3. Панель → «Qo'ng'iroqlar» → «Klinika telefoni (MicroSIP)» → **Ulash**. MicroSIP на несколько секунд закроется и откроется (настройки меняются только при закрытом MicroSIP — иначе он их перезаписывает). Не нажимать во время разговора.

Что меняет «Ulash» в `MicroSIP.ini` (рядом сохраняется копия `.cerebro-backup`): команды событий звонка → маленький помощник Cerebro в `%ProgramData%\Cerebro-ms-…` (папка закрыта от других пользователей Windows), `autoRecording=1`, папка записей. «Uzish» возвращает прежние значения.

Если MicroSIP уже подключён к DentaCRM — панель спросит, переключить ли на Cerebro.

## Ограничения и что важно знать
- MicroSIP должен стоять на ПК с сервером Cerebro (события и записи передаются файлами). Несколько ПК регистратуры — следующий шаг.
- Записи — в `data\recordings` (MP3, если рядом с MicroSIP есть `lame_enc.dll`, иначе WAV ≈ 1 МБ/мин).
- Короче 8 секунд — не разбираются. Без ключа распознавания речи (VoiceLab/Gemini/Groq) записи сохраняются, но без текста и разбора.
- Запись разговоров: сообщите клиентам (например, приветствием у оператора «разговор записывается»).

## Что проверено и что нет
- **Проверено автотестом** (`npm run test:phone`, 29 проверок) на этом ПК: помощник собирается настоящим `csc.exe`, права папки ставятся настоящим `icacls`, изменяется копия **настоящего** `MicroSIP.ini` 3.22.18 (UTF-16), события идут через настоящий помощник и папку; пропущенный → заявка; «📞» → набор; запись → разбор (фейковые распознавание и ИИ); отключение возвращает ini как было.
- **Не проверено**: сам MicroSIP не запускался (чтобы не открывать окна на экране) и реальный звонок через оператора не делался — нужен SIP-логин. Имя файла записи MicroSIP Cerebro не угадывает: файл ищется по времени разговора (на живом звонке это первое, что надо проверить).
